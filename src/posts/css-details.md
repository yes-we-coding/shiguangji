做页面时经常遇到一种情况：布局都对，颜色也对，但就是"差点意思"。多数时候，差距就在几个不起眼的细节上。

## 行高是中文排版的命门

默认行高对中文来说太挤了。正文的 `line-height` 给到 1.7 左右，呼吸感立刻不一样：

```css
body {
  font: 16px/1.75 sans-serif;
}
```

## 过渡动画的黄金时长

悬停反馈的过渡时长，0.15s 太仓促，0.5s 太拖沓，**0.2s ~ 0.25s** 刚刚好。而且只对变化的属性做过渡，不要写 `transition: all`：

```css
.button {
  transition:
    color 0.2s,
    border-color 0.2s;
}
```

## 留白要舍得

元素之间的间距，宁多勿少。一个经验：觉得"差不多了"的时候，再加 4px。卡片内边距小于 16px 的界面，很少有不局促的。

## 阴影要淡

生硬的阴影是廉价感的来源。好阴影的标准是"几乎注意不到，但没有它就发飘"：

```css
.card {
  box-shadow: 0 6px 20px rgba(66, 60, 50, 0.07);
}
```

低透明度、大模糊半径，阴影颜色带一点环境色的倾向，比纯灰更自然。

## 结语

设计里没有玄学。把这些像素级的细节做到位，"舒服"自然就来了。
