想了很久的个人博客，终于在这个夏天动手了。这篇记录从选型到搭建的完整过程，也算给这个博客开个头。

## 为什么是 Vite + Vue 3

需求其实很简单：一个安静写字的地方，加载要快，维护要省心。对比了几个方案：

- **Hexo / Hugo**：成熟省心，但定制起来要摸一套模板语法，少了点自己动手的乐趣
- **Nuxt**：功能强大，但对一个纯静态博客来说有点重
- **Vite + Vue 3**：自己搭骨架，每一行代码都认识它，冷启动毫秒级

最后选了最"亲手"的方案。博客这种小项目，正适合拿来练手和打磨细节。

## 组件拆分思路

页面拆成三块：头部、主栏、两侧的小部件栏。小部件全部独立成组件，互不依赖：

```
src/
├── components/   # SiteHeader、PostList、TodoList……
├── data/         # 文章数据
└── posts/        # Markdown 文章
```

这样做的好处是，想加一个新部件时，只需要写一个新组件，再放进布局里，不动任何已有代码。

## 配色这件事

试了很多配色，最后定了"暖纸白 + 鼠尾草绿"：低饱和、护眼，像一张摊开的稿纸。深色模式也不是纯黑，而是带一点暖意的深褐黑。

```css
:root {
  --bg: #faf9f7;
  --accent: #7c9a82;
}
```

所有颜色都收敛在 CSS 变量里，深色模式只需要覆盖一组变量，组件样式一行不改。
