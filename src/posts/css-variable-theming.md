给博客调整配色时遇到一个问题：想让侧边栏的小组件各有各的颜色——时钟蓝色、待办杏色、番茄钟橙色——但每个组件内部都写着 `var(--accent)`，难道要一个个进去改？

不用。CSS 自定义属性有个关键特性：**变量的继承看的是 DOM 树，跟样式表写在哪、是不是 scoped 完全无关**。

## 原理

Vue 的 scoped 样式只是给选择器加了属性选择器，变量依然沿 DOM 树正常级联。所以在组件根元素上覆盖变量，整个子树都会跟着变：

```css
/* 全局定义"三件套" */
:root {
  --accent: #7c9a82;
  --accent-deep: #5f7d66;
  --accent-soft: rgba(124, 154, 130, 0.12);
}

/* 色调类：只负责覆盖变量 */
.tint-sky {
  --accent: var(--sky);
  --accent-deep: var(--sky-deep);
  --accent-soft: var(--sky-soft);
}
```

```html
<!-- 挂上类，整个组件自动换色 -->
<DateTimeCard class="tint-sky" />
```

组件内部的 `var(--accent)` 一行不改，解析到的就是覆盖后的值。

## 为什么是三件套

单个颜色不够用：一个色调在实际界面里至少需要**主色**（填充、图标）、**深色**（文字，保证对比度）、**浅色**（背景、hover）三个层次。约定好 `--accent / --accent-deep / --accent-soft` 这套接口，换肤就是成组替换。

## 经验

1. 组件样式里永远写 `var(--accent)`，不写具体色值——可换肤性是"约定"出来的
2. 主题变量要分层：底色、文字、主色、辅色、阴影，各司其职
3. 这套机制也让回滚变得极便宜：删掉色调类，一切回到默认主题

> 设计系统的本质不是一组颜色，而是一组"可以安全替换的颜色位置"。
